# SteinsGate · 命运石之门

AstrBot 的命运石之门主题插件，支持辉光管世界线变动率图片、特殊世界线资料、年表查询和 D-QQ，可通过指令或 LLM 自然语言调用。

## 功能

- **世界线变动率**：生成指定或随机变动率的辉光管图片。
- **特殊世界线**：随机抽取或查询指定世界线，发送图片与剧情介绍。
- **年表查询**：查询某一年的全部事件，或随机抽取一条事件。
- **D-QQ**：发送带过去或未来时间的合并转发消息，正文只保留用户消息。

世界线资料和年表包含剧透。

## 安装

在 AstrBot 插件管理页面选择从链接安装，输入：

```text
https://github.com/Shennoter/astrbot_plugin_steinsgate
```

也可下载插件 ZIP，通过本地上传安装。需要 AstrBot `>=4.16,<5`，依赖由 AstrBot 自动安装。

## 自然语言调用

使用支持工具调用的模型，并在当前人格或 Agent 中启用以下工具：

| 工具 | 示例 |
| --- | --- |
| `steinsgate_divergence` | 生成一张 1.048596 的世界线图片 |
| `steinsgate_special_worldline` | 随机抽一条特殊世界线，介绍一下剧情 |
| `steinsgate_timeline` | 命运石之门 2010 年发生了什么？ |
| `steinsgate_send_dqq` | 用 D-QQ 把「不要放弃」显示成五天前发来的消息 |

群聊中仍需 @ 机器人或满足 AstrBot 的唤醒规则。工具会直接将结果发送到当前会话。

## 指令

以下以默认唤醒前缀 `/` 为例，`[]` 表示可选参数。

| 指令 | 功能 |
| --- | --- |
| `/div [变动率]` | 生成指定或随机世界线图片，别名：`世界线` |
| `/udiv` | 随机发送特殊世界线图片与资料 |
| `/timeline [年份]` | 查询指定年份全部事件；不填则随机抽取，别名：`年表` |
| `/dqq 内容 [秒数]` | 发送 D-QQ，别名：`D-QQ`、`发送` |
| `/sghelp` | 查看帮助 |

变动率支持 `1.048596`、`1048596` 等格式，小数不足六位时补零。负数如 `-0.275349` 的第一根辉光管显示为熄灭。

### D-QQ

```text
/dqq 来自未来的消息
/dqq 来自过去的消息 -432000
/dqq "今天的幸运数字是 42" -86400
```

时间单位为秒，相对当前时间计算，负数表示过去，默认 `432000`（未来五天）。正文以数字结尾时请用英文引号包裹，避免被识别为时间参数。

D-QQ 会**立即发送**，只改变转发记录的时间，不是定时发送或提醒。正文不附加时间标签。

- 自定义转发时间需要 OneBot v11 协议端支持；NapCat 需要 Packet 模式正常工作，最终显示以 QQ 客户端为准。
- 其他平台或合并转发失败时，会改为发送用户消息的普通文本。
- 默认支持无前缀的 `dqq`、`D-QQ`、`发送`，可在配置中修改或关闭，避免与日常消息冲突。

## 配置

在 AstrBot 插件配置页修改：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `unique_probability` | `50` | 随机变动率命中特殊世界线的概率，范围 0～100 |
| `dqq_commands` | `["dqq", "发送", "D-QQ"]` | 无前缀 D-QQ 触发词 |
| `enable_bare_dqq` | `true` | 启用无前缀 D-QQ |
| `dqq_default_seconds` | `432000` | D-QQ 指令的默认时间偏移，单位为秒 |

可在 `data/plugin_data/astrbot_plugin_steinsgate/` 下编辑 `UniDiv.json` 和 `Timeline.json` 自定义资料，修改后即时生效，插件更新不会覆盖已有数据。
